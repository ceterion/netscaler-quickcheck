# netscaler-quickcheck v17.41 (2026-10-28)

Crashes: report more, rate harder. Rules stand 2026-10-28d. Everything else as in `v17.40.md`.

## New in v17.41

- **Every crash is at least yellow**; no crash stays INFO. Red when: nsaaad on a SAML gateway twice in one day (exploitation pattern per CTX697174/CTX697191, regardless of build), nsaaad with SAML and an open SAML CVE, httpd on a build vulnerable to PHP2Shell, nsppe with DTLS errors, any process three times in one day, the same process on three or more days (new cumulative file `ns_quickcheck_observed_crashes.tsv` per appliance), or a crash within 120 seconds after a SAML request (nsaaad) or an external management request (httpd); the requesting address is listed as `crash_trigger` in the address lists and the share file.
- **More evidence:** Apache worker crashes from the web server error log (`HTTPERR_CRASH_RE`, `AH00052: child pid ... exit signal ...`, the most likely trace of PHP2Shell), core files without a log line (after rotation or for unmonitored processes), kernel panic or trap (`KERNEL_PANIC_RE`, red), memory pressure (`KERNEL_MEM_RE`, yellow), and a reboot without a reboot/shutdown command in the hour before (yellow, only when logs from before the boot exist).
- `crashes=<n>` in the result line and JSON. New test log `crash-extra.log`; fixtures carry a planned reboot line.
