# netscaler-quickcheck v17.42 (2026-10-28)

Core handling, verdict text, stock hash 73.49. Rules stand 2026-10-28e. Freeze for the release. Everything else as in `v17.41.md`.

## New in v17.42

- Compressed cores (`<proc>-<pid>.gz`, as left by an upgrade) are attached to their event instead of being counted as phantom events.
- Numbered directories `/var/core/<n>` are directory cores with unknown process. Empty and created within 15 minutes after boot: INFO "boot aftermath" (`CORE_BOOT_LEVEL=info`, default); `CORE_BOOT_LEVEL=yellow` makes it a crash event. Not empty or later: a crash event, yellow.
- The verdict sentence "attack attempts, no mitigation policy" appears only when a CVE is open; on a fixed build the policy has no effect.
- Rules stand 2026-10-28e: stock hash of `ns_monuploadd_err.pl` for 14.1-73.49, confirmed by two independent appliances; the INFO "no stock value" becomes `OK`.
