# netscaler-quickcheck v17.40 (2026-10-28)

Pitboss process lines, consistent event times. Rules stand 2026-10-28c. Everything else as in `v17.39.md`.

## New in v17.40

- Lines of the pitboss process itself (`pitboss[28]: proc nsaaad (974) SIGNALED`, `EXITED with status 0x8b`) are assigned to the crash event; the signal is derived from the exit status (128 + n) when no kernel line exists. Rules stand 2026-10-28c carries the pattern, verified in the lab.
- Event times are taken uniformly from the syslog header (local time of the appliance); before, PPE lines used their GMT field and pitboss lines local time, so one event could show two clocks.
