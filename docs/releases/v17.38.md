# netscaler-quickcheck v17.38 (2026-10-28)

Fixes from the lab run of 2026-10-28. Rules stand 2026-10-28 unchanged. Everything else as in `v17.37.md`.

## New in v17.38

- **Verdict text** names the open CVEs and bulletins with the target build ("verwundbar gegen CVE-2026-109618, CVE-2026-109619 (CTX697263, aktiv ausgenutzt). Ziel: 14.1-73.49"); before it was hard-wired to CTX697096 and the target was empty.
- **`vuln96`** now means strictly "a CTX697096 CVE open"; before it was set for any open CVE. New result field **`vuln_open=<n>`** with the number of open CVE rows across all bulletins. Collector: read `vuln_open` for "anything open", `vuln96` only for the September bulletin.
- Login summary lists the account per source ("console:nsroot (7) console:root (3)" instead of "console (7) console (3)").
- **Anonymization:** host names from URLs in config values (`-wihome`, `-storefronturl`, redirects) and domains from `-ntDomain`, `-domain`, `-dnsSuffix`, `-emailDomain` are now mapped; in the lab run the StoreFront URL and the NT domain were in clear text in the anonymized copy. Re-create anonymized copies made with 17.37 or earlier before sharing.
