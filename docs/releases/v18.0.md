# netscaler-quickcheck v18.0 (2026-11-04)

Message catalog and English output. Rules stand 2026-10-28e unchanged.

## New in v18.0

- **Message catalog.** Every report, terminal and list text now lives in `ns_quickcheck.msg.de` and `ns_quickcheck.msg.en` (`KEY<TAB>text`, placeholders `%1`..`%9`) next to the script; the script contains keys only. German is mandatory and the default; `--lang en` or `LANG_QC=en` in the config selects English. A key missing from the chosen catalog falls back to German and is counted in the header. A further language is one more file with the same keys.
- **Finding codes.** Every finding in the JSON carries `code`, the catalog key; the result line carries `lang` and `msg_sha256`. Collectors should key on `code`.
- **German output unchanged.** The German report of 18.0 is byte-identical to 17.44 on all ten fixtures (reports, JSON apart from the new fields, anonymized copies, address lists, share files). `docs/release.sh` now compares every fixture against normalized reference reports under `docs/testdata/reference/` (German for all fixtures, English for `compromised` and `crash`) and checks both catalogs for equal keys and placeholders; `docs/tools/refgen.sh` renews a reference after a deliberate wording change.
- Side effects of the rebuild: six places where the script parsed its own output (block date, injection sources, management request counts, SSH failures, cumulative list start date, note stripping in anonymized copies) now carry data in fields; the anonymizer's reserved words come from both catalogs.
- Trusted list: validity is shown as "gueltig bis <date>" / "valid until <date>" or explicitly "gueltig unbefristet" / "valid without expiry"; the remark also appears on the address-list line of the original report (removed in anonymized copies). An address whose trusted entry has expired is rated normally and carries the hint "[in trusted_ips, abgelaufen am <date>: Eintrag verlaengern oder loeschen]" on its findings and ", trusted abgelaufen am <date>" in the address lists.
- Texts of the rules file (CVE descriptions, comments) are not translated.
- Lab and operator runs of 2026-11-04 fixed before release: three FreeBSD sh parser crashes on 18.0 constructs (patterns with quotes or parentheses in `${}`), missing `comm` on the appliance, an empty source detail on injection findings from responder lines (tab fields collapsed under IFS), and a tab inside the remark of a `;`-separated trusted or block list line that shifted the remark into the date column. New fixture `responder` and platform lints 5 and 6 in `release.sh`.

## Update

Replace `ns_quickcheck.sh` and add `ns_quickcheck.msg.de` (mandatory) and `ns_quickcheck.msg.en` in `/var/nssnapshot/`, `chmod 600`. The script aborts with a clear message if `ns_quickcheck.msg.de` is missing. Optional in `ns_quickcheck.conf`: `LANG_QC=en`.
