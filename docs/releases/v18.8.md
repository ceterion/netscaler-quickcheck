Two corrections from a lab run of 18.7. Rules stand 2026-11-05d and catalogs unchanged.

## Fixed in v18.8

- **Crash events outside the window.** The crash check selected log files by modification time and then counted every event in them, including those before the window start. On a lab appliance eight `sh` segfaults eleven days old produced a red finding and `FORENSICS_FIRST`. Events with a readable timestamp before the window start are now dropped (Pitboss, kernel, Apache error log); events without a readable timestamp are kept; `/var/core` directories keep their directory time. Fixture `crash-old` (two events eleven days old plus a header line, fixed reference time via `refgen.now`, window via `refgen.hours`).
- **Log stock reach from the first readable line.** The rotation check took the first line of the oldest file; a header or a torn line made it fall back to the file time and report a reach of "today". Now the first line with a readable date within the first 50 lines (`log_date_first`).
- **Test hook `QC_NOW`** (offline mode only): fixed reference time in epoch seconds so fixtures with window boundaries give stable references; `refgen.sh` and `release.sh` read `refgen.now` and `refgen.hours` per fixture.
