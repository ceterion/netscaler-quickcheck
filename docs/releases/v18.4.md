# netscaler-quickcheck v18.4 (2026-11-05)

Status: in Arbeit

Bug fix in the message catalog engine. Rules stand 2026-11-05d unchanged.

## Fixed in v18.4

- **`msg()` endless loop.** Since 18.0 the placeholder substitution replaced `%1`..`%9` in a loop "while the placeholder occurs"; a value that itself contained `%` followed by a digit (URL-encoded payloads such as `%2527%2522` in CSP reports, injection and probing lines) re-inserted the placeholder and the loop never ended. On a customer gateway the shell burned minutes of CPU in block 4 and the cron run had to be aborted (first seen with 18.2, whose CSP baseline INFO put scanner values into a `%2` template). The final cleanup also stripped `%<digit>` from values (`%2527` became `527`). Substitution now runs left to right without re-scanning inserted values, and unassigned placeholders are removed from the template before substitution, never from values. Test log `msg-percent` in `release.sh` runs every catalog template against values containing `%1`..`%9` and fails on growth or loss.
- `v18.3.md` frozen (ran on the customer gateway).
