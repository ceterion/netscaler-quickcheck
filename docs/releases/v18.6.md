# netscaler-quickcheck v18.6 (2026-11-06)

Status: in Arbeit

Measurement and wording release. Rules stand 2026-11-05d unchanged.

## New in v18.6

- **Profiling inside block 4.** `QC_PROFILE=1` now marks every sub-check: `b4-injection`, `b4-crash`, `b4-dropper`, `b4-httperr` (web server error log, PHP, probing), `b4-mgmt`, `b4-auth`, `b4-aaa`, `b4-shell`, `b4-trust`. On a customer gateway block 4 took 115 of 140 seconds; the marks show which sub-check.
- **INFO values sanitized.** Non-ASCII bytes in INFO lines are replaced by `.` as in detail lines (raw bytes from scanner values stood in the CSP baseline line).
- **CSP finding text.** The explanation now describes the mechanism precisely: the browser posts a violation report (`application/csp-report`) to the `report-uri` of the logon page's policy, NetScaler logs it, the fields are client-controlled. README 15 (both languages) adds the browser route to the `report-uri` when `curl` shows no header.
- **Anonymizer, token-based.** The one-pattern-per-class approach of 18.5 still built one alternation of all account names; with 4,000 accounts perl spent a minute on an 87-line report. Addresses and accounts are now matched as tokens with a hash lookup, independent of table size (87-line report: 71 s to 1 s); host names keep the alternation (few entries, needed inside other strings). Output byte-identical on nine fixtures. Variants of one account (raw spelling, umlauts, dotted form, lower case) now get the same replacement, and tokens with non-ASCII bytes are matched, so an umlaut account no longer survives in the anonymized copy (`release.sh` checks this on the `umlaut-account` fixture).
- **Release checks.** `docs/tools/refseq.sh`: two runs in one report directory (`shared-hit`, then `clean`) with references for report, JSON (with `code`), account files, cumulative lists and anonymized report; `docs/tools/genperf.sh`: synthetic fixture with 2,000 addresses and 50,000 AAA lines, `release.sh` fails above `PERF_MAX_S` (120 s). Seven new fixtures: `late-other`, `nfactor-partial`, `shared-machine`, `csp-baseline`, `shell-nologin`, `inj-percent`, `umlaut-account`.
- `v18.5.md` frozen (ran on the customer gateway).
