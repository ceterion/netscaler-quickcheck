# netscaler-quickcheck v17.36 (2026-10-27)

Change times on the appliance, directory rules discouraged. Rules stand **2026-10-28** (corrected PHP2Shell fix builds, see `rules-2026-10-28.md`). Everything else as in `v17.35.md`.

## New in v17.36

- Change time per web file is now formatted with perl; the awk `strftime()` of 17.34 does not exist in the appliance's BWK awk, so the times were missing on the appliance. New platform lint in `docs/release.sh` rejects GNU-awk functions.
- Whitelist stance: directory rules (`.../`) remain supported but are not recommended; the run header counts them as INFO. `WORKFLOW.md` and `WORKFLOW.de.md` carry a WARNING block: a pin releases exactly that content (diff before pinning), a file rule without a hash releases the name only, directory rules hide new files. Template rewritten with pins only; README 15 table adjusted.
