# netscaler-quickcheck v18.3 (2026-11-05)

Runtime release. Rules stand 2026-11-05d unchanged.

## New in v18.3

- **Log cache.** The `ns.log` family and `messages` are decompressed and de-duplicated once into the working directory when the archives together are below `LOG_CACHE_MAX_MB` (default 500); every later read uses the cache instead of decompressing all archives again. v18.2 read them 16 times, plus three more passes for the CSP block, which on a gateway with a two-day rotation meant minutes of management CPU and an aborted cron run.
- **CSP block in one pass.** Hits, baseline and top sources come from one extraction.
- **Profiling.** `QC_PROFILE=1` (config or environment) prints seconds per block to stderr and as an INFO in block 6.
- **Gateway VIPs** for the firewall search also from `add cs vserver`; `0.0.0.0` is skipped.
