# netscaler-quickcheck v18.7 (2026-11-06)

Status: in Arbeit

Small robustness release. Rules stand 2026-11-05d unchanged.

## New in v18.7

- **Windows line endings in operator files.** `ns_quickcheck.conf`, whitelist, block and trusted lists and `ns_quickcheck.rules.custom` with CRLF are read with the CR removed (cleaned copy in the working directory, mode 600) and an INFO in the header names the files. Before, a CRLF config produced ": not found" per line and `HOURS` was no number (customer gateway, 2026-11-06).
- **Error messages before the catalog is loaded** (option errors, config errors) use the German catalog next to the script when present, instead of printing the message key.
